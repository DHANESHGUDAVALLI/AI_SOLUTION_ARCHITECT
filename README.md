# AI Solution Architect

## Overview

**AI Solution Architect** is an AI-powered web application that helps users transform software ideas into well-structured solution architectures. It automates the process of gathering project requirements, generating technical documentation, creating architecture diagrams, and providing implementation guidance.

The platform is designed for students, developers, startups, software engineers, and organizations that want to accelerate software planning and architecture design using Artificial Intelligence.

# Workflow

1. User logs into the application.
2. Creates a new software project.
3. Enters project requirements.
4. AI analyzes the provided information.
5. System generates:

   * Solution Architecture
   * Technology Recommendations
   * System Design
   * Documentation
6. User reviews and edits the generated solution.
7. Final architecture can be exported as a PDF report.

# Installation

## Clone the Repository

```bash
git clone https://github.com/DHANESHGUDAVALLI/AI_SOLUTION_ARCHITECT.git
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd backend
pip install -r requirements.txt
python main.py
```
